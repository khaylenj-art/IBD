# Institute of Building Design (IBD)

Official online professional education platform developed in collaboration between **An Architect** and the **South African Institute of Building Design (SAIBD)**—a recognised voluntary association established under the Architectural Profession Act No. 44 of 2000.

---

## Overview

The Institute of Building Design provides accredited, peer-reviewed professional development programmes tailored for built environment professionals in South Africa (architectural draughtspersons, technologists, architects, structural engineers, and quantity surveyors). The platform is specifically designed to eliminate the CPD renewal scramble and provide accredited SACAP Category 1 and Category 3 points.

## Local Development & Server

To run and preview the website locally:

```bash
# Using Node.js standard built-in server (included in server.js)
node server.js
```

The site will be accessible at:
```
http://localhost:8080
```

Alternatively, open [`index.html`](index.html) directly in any modern web browser.
